## 1. 往届获奖作品：哪些能改造，哪些不能

| 往届作品（届次/奖项） | 本质 | 能改造成决策智能体吗 |

| 天工大·福师大·广科·安建大 ViT 推理优化（十·国一/全球特等奖） | 性能工程 | ❌ 不能。那是赛题1/挑战赛的活，与决策无关 |

| 华师 寻医有道 智能问诊（八·中国特等奖） | 问答 | ⚠️ 可加"挂号科室/检查开单"决策 |

| 华南师大 智能反诈（七·国三，金融唯一） | 识别 | ✅✅ **最强改造对象**：拦截/放行/限额/人工核验是标准动作空间 |
| 武理工 电力巡检无人机（十·全球特等奖） | 巡检+自主判断 | ✅ 航线/悬停细看/派工单 |
| 同济 蛇形机器人发动机检测（八·全球特等奖） | 运动+检测决策 | ✅ 探入路径、检测点排序 |
| 大工 黑Coal 煤质检测（八·国二） | 检测 | ⚠️ 改成"配煤掺配决策"才是决策 |
| 地大 岩矿样本分析（九·全球一等奖） | 检测 | ⚠️ 改成"选矿流程参数决策" |
| 西交 电力数字化（七·行业赛特等奖） | 调度 | ✅ 负荷预测→调度动作，决策密度极高 |
| 清华 智慧公路（七·行业赛特等奖） | 交通管控 | ✅ 信号/限流/诱导决策 |
| 华师 Ascend Sentinel 校园暴力干预（十·国一） | 预警+干预 | ✅ 干预动作选择，可进化（校情记忆） |
| 大工 SEED 城市隐患（十·国一） | 发现+研判 | ✅ 隐患分级 + 处置派单 |
| 厦大 声域领航 博物馆（八·国一） | 导览推荐 | ⚠️ 弱决策（路线推荐可算策略） |
| 第九届 楼宇巡检机器人（全球） | 巡检决策 | ✅ 路线 + 异常处置 |

**结论**：往届四方向作品里，真正"决策密度高"的是——**反诈处置、电力调度/巡检、校园安全干预、城市隐患派单、脑机闭环刺激、机器人行动**；而"病理问答 + ViT 推理优化"是本届全国扎堆的红海，且**恰恰不是决策智能体**，避开它反而是优势。

## 2. 「可进化」的五个层次

按实现难度从低到高，建议至少做 **2 层**，第 3 层是拿高奖的分水岭。

| 层次 | 机制 | 具体做法 | 可度量指标 |
|---|---|---|---|
| L1 记忆进化 | 情景记忆 + 案例复用 | 失败轨迹写入向量库，下次检索相似案例作为提示 | 重复错误率下降 |
| L2 反思进化 | Reflexion 式自我批评 | 每轮结束生成"教训"并写入策略提示 | 同类任务成功率随轮次上升 |
| L3 策略进化 | 策略库/提示自更新、bandit 选择 | 维护多套策略，按历史收益用 UCB/汤普森采样选，胜者留存 | 平均步数下降、成本下降 |
| L4 工具/技能进化 | 技能自生成（Voyager 式） | 把成功动作序列固化为可复用技能/新 MCP 工具 | 技能库增长曲线、新任务零样本成功率 |
| L5 模型进化 | 交互轨迹回流微调 | 用 ModelEngine 的数据处理+微调链路，把高分轨迹做 SFT/DPO | 微调前后同一测试集提升 |

**华为栈落点**：
- ModelEngine：数据清洗/知识生成 → 微调 → 部署 → RAG，正好承接 L5 和 L1 的知识库。
- Nexent：多智能体编排 + 工具（MCP）调用 + 知识库检索，承接 L1–L4 的运行骨架。
- 建议架构：`感知/数据 → Nexent 智能体（规划+决策）→ 工具层（真实动作：工单/API/设备指令）→ 反馈与评估 → 记忆库/策略库 → 回流微调`

## 3. 四方向选题库

每条都给出**动作空间**（评委必问）、**进化闭环**（怎么变好）、**演示脚本**（现场怎么演）。

### 3.1 医疗健康

**M1｜肿瘤病理"下一步检查"决策智能体**（改造自 MAPLE / CARE-Agent，避开纯问答）
- 场景：拿到病理切片与报告草稿后，决定下一步动作，而非直接生成报告。
- 动作空间：`申请免疫组化(IHC)标记 X / 申请补染 / 申请分子检测 / 申请会诊 / 直接签发`
- 状态：WSI 特征 + 已有报告 + 指南知识库 + 历史相似病例
- 进化：每次"决策被病理医生否决"→ 记录否决理由 → 更新策略提示与案例库；度量"不必要检查率↓、关键标记漏检率↓"
- 演示：同一病例第 1 轮漏掉 HER2，医生否决 → 反思写入 → 第 2 轮同族病例直接补上
- 参考：[上交 MAPLE](https://www.si.sjtu.edu.cn/content/news-detail?params=9556e403b61f4b3c979957a80787428e&menuIds=2,8,17)、[北理工 CARE-Agent](https://bit.edu.cn/xww/zhxw/jxky1/cd07be3d5c05426892baec05ab60dd03.htm)

**M2｜意识障碍患者促醒治疗闭环决策**（改造自 MindAligner）
- 动作空间：`调整刺激参数 / 更换刺激范式 / 延长/缩短训练 / 转康复科`
- 进化：以 EEG 响应度为奖励，个体化策略在线更新（这是真正的 RL 场景）
- 演示：3 个虚拟患者，策略在 20 轮内收敛到各自最优范式
- 参考：[华师 MindAligner](http://news.scnu.edu.cn/72786/338)

**M3｜居家养老机器人"事件响应"决策**（改造自 U-care Yuka / HomeAgentMaster）
- 动作空间：`继续巡视 / 靠近询问 / 呼叫家属 / 呼叫 120 / 记录归档`
- 进化：误报（老人只是弯腰）与漏报都进记忆，阈值与话术策略自调
- 演示：跌倒 vs 捡东西 vs 蹲下系鞋带三类混淆场景，误报率随轮次下降
- 参考：[华师 U-care](http://gxb.scnu.edu.cn/a/20260506/1815.html)、[上交 HomeAgentMaster](https://si.sjtu.edu.cn/content/news-detail?params=3ec3bc8a4b614bc9ae4806569a708f4e&menuIds=3,26,28)

### 3.2 金融（往届几乎是空白，差异化最大）

**F1｜电诈交易实时处置决策智能体**（改造自华南师大反诈，金融唯一获奖样本）
- 动作空间：`放行 / 弹窗提醒 / 二次人脸核验 / 限额 / 冻结 / 转人工`
- 奖励设计（关键）：拦截正确 +10，误伤正常用户 −8（成本不对称），漏放 −20
- 进化：新型诈骗话术/账户模式进案例库，处置策略按"资损率 vs 误伤率"帕累托前沿自更新
- 演示：回放真实脱敏交易流，展示"第 1 天误伤 12%、第 30 天误伤 3% 且资损不变"
- 参考：[华南师大 智能反诈骗小组（七·国三）](http://news.scnu.edu.cn/57745)

**F2｜信贷尽调"补件与结论"决策智能体**
- 动作空间：`要求补充材料 X / 发起外部核验 / 提额 / 降额 / 拒贷 / 转人工审批`
- 进化：审批员否决理由回流；度量"平均补件轮次↓、一次通过率↑"
- 演示：三家企业财报 + 流水，智能体自主决定补什么，第 2 轮明显更准

**F3｜保险理赔单证审核与立案决策**
- 动作空间：`立案 / 补件 / 转查勘 / 拒赔 / 反欺诈调查`
- 进化：欺诈样本记忆 + 规则自更新；度量"单均审核时长↓、误拒率↓"
- 说明：F1–F3 的共同优势是**动作空间天然离散、成本可量化**，最适合展示"进化"。

### 3.3 制造 / 工业 / 能源

**I1｜电力巡检无人机"看什么、报什么"决策智能体**（改造自武理工全球特等奖）
- 动作空间：`继续巡航 / 降高悬停细看 / 换角度复拍 / 判定缺陷等级 / 派检修工单`
- 进化：漏检缺陷（事后检修发现）回流，航线与判定阈值自调；度量"单位架次发现缺陷数↑、无效悬停↓"
- 参考：[武汉理工 电力巡检无人机（十·全球特等奖）](https://m.10100.com/article/149725118)

**I2｜产线异常处置决策智能体（填补往届空档）**
- 场景：注塑/压铸/SMT 产线出现工艺漂移，决定"停线/降速/换刀/调参/呼叫工艺工程师"
- 动作空间：上述 5 类 + 参数微调幅度
- 进化：每次处置后的良率变化作为奖励，策略在线更新；度量"停线时长↓、良率↑"
- 为什么好：往届制造类**全是检测/巡检，没有一条做"处置决策"**，空白即机会

**I3｜配煤掺配决策智能体**（改造自大工 黑Coal 煤质检测）
- 动作空间：`调整煤种配比 / 更换煤源 / 降低掺配比例`
- 进化：以"入炉煤质达标 + 成本最低"为双目标，策略随煤价与库存漂移自更新
- 参考：[大连理工 黑Coal（八·国二）](https://ss.dlut.edu.cn/info/1571/1851.htm)

### 3.4 政务 / 公共治理

**G1｜12345 接诉即办"派单与回访"决策智能体（往届完全空档）**
- 动作空间：`派 A 部门 / 派 B 部门 / 联合派单 / 直派社区 / 认定咨询类直接答复 / 升级督办`
- 状态：工单文本 + 历史同类工单处置结果 + 部门职责库 + 时限压力
- 进化：以"退单率、超期率、群众满意度"为奖励；退单理由进记忆，派单策略自更新
- 演示：100 条历史工单回放，退单率从 18% 降到 6%
- 为什么好：政务方向往届只有"看得见的安全"，**没有一条做"办事流程决策"**

**G2｜城市安全隐患"分级与处置"决策智能体**（改造自大工 SEED）
- 动作空间：`立即处置 / 限期整改 / 观察 / 上报上级 / 复查排期`
- 进化：隐患演化结果（是否成灾）回流，分级阈值自调
- 参考：[大连理工 SEED（十·国一）](https://m.thepaper.cn/newsDetail_forward_33171564)

**G3｜校园安全风险干预决策智能体**（改造自 Ascend Sentinel）
- 动作空间：`忽略 / 记录 / 通知班主任 / 通知心理老师 / 通知安保 / 启动应急`
- 进化：干预后事件是否升级作为奖励；度量"误报打扰↓、真事件响应时长↓"
- 参考：[华中师大 Ascend Sentinel（十·国一/全球二等奖）](http://cs.ccnu.edu.cn/info/1055/10906.htm)

## 6. 避坑清单

1. ❌ 做成"能聊天的行业助手"——那是赛题2 的地盘，赛题3 必须有动作。
2. ❌ 只有一次成功演示，没有"变好"的证据——**必须录训练/进化过程视频**，现场只放结果会被质疑造假。
3. ❌ 进化不可度量——至少给两条曲线：成功率 vs 轮次、成本/时延 vs 轮次。
4. ❌ 动作空间含糊（"智能体自动处理"）——必须列出离散动作集与触发条件。
5. ❌ 纯软件无载体——往届特等奖几乎都有硬件或真实系统对接；至少接一个真实 API/设备/仿真环境。
6. ❌ 忽略合规——医疗（不能给诊断结论）、金融（不能承诺收益/直接冻结）、政务（不能替代行政决定）都要写"人在环"。
