# v1｜规则总览

- 规则集版本：v1（基于：无）
- 来源：仿真内部规则（非官方要求）

风险规则命中表示出现某种需要关注的资金特征。反向规则命中表示存在可能说明账户行为正常的证据。反向规则不单独推翻风险规则，只用于在工单中列出反向证据，并在部分情况下把状态定为“证据不足”。

本版本包含的规则：
- R01 快进快出（风险规则，高）
- R02 短时多来源集中转入（风险规则，中）
- R03 拆分转出（风险规则，高）
- R04 余额清零（风险规则，中）
- R05 新开账户大额转入（风险规则，中）
- R06 夜间大额（风险规则，中）
- R07 多层链路（风险规则，高）
- R08 首次对手大额转入（风险规则，中）
- R09 稳定工资收入（反向规则，低）
- R10 商户经营特征（反向规则，低）

本条属于v1。仿真内部规则，阈值是本作品为仿真场景设定的参数，不是任何监管机构的标准。
