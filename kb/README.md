# kb/

知识库素材目录，由乙维护。这里的文件会上传到 Nexent 的两个知识库，供智能体检索规则依据和案例。

## 两个知识库

| 知识库 | 内容 |
|---|---|
| `涉诈规则库` | 规则说明、法规摘录、规则版本差异 |
| `涉诈案例库` | 丙提供的公开案例摘要 |

知识库名称只能含中文或小写字母，不能有数字、空格、下划线。

## 计划放入的文件

| 文件 | 内容 | 来源与时间 |
|---|---|---|
| `rules_v1_draft.md` | R01 至 R10 的草稿，条件照抄 `Data and Rules/rules/rules_v1.yaml` 的 `desc` | 乙手工整理，第 2 天 |
| `rules_v1.md` | 由 `core/export_rules_md.py` 从 YAML 生成，替换草稿 | 甲生成，第 3 天 |
| `rules_v2.md`、`rules_diff_v1_v2.md` | v2 规则及与 v1 的差异 | 甲生成，第 5 天 |
| 法规摘录 | 如有 | 丙提供 |
| 案例摘要（`.md`） | 每篇 300 至 600 字，写“手法 — 资金特征 — 可对应规则”，注明来源链接与访问日期 | 丙提供，第 2 天；未到时先用占位 |

## 注意

- 文件中**不放任何账户号和交易号**，避免智能体把知识库内容当成交易证据。
- 规则文件以 YAML 为准，不要手工改数字；规则变了就重新生成并重传。
- 规则来源统一写“仿真内部规则（非官方要求）”，不得冒充官方标准。
