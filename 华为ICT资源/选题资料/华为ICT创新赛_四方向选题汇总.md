# 华为 ICT 大赛「创新赛」选题汇总（医疗 / 金融 / 制造 / 政务）
## 1. 说明
- 华为官方获奖名单只公布"奖项 / 赛道 / 国家 / 学校 / 姓名"，**不含作品名**，故作品名与摘要均取自高校新闻稿、地方媒体与参赛队自述。
- "创新赛"在不同届次名称有别：第七届分"创新赛（创新赛道）+ 行业赛（智慧公路、电力数字化）"，第八至十届为"创新赛"，第十届起改为企业命题（病理问答、ViT 推理优化、低空航行等）。

|---|---|---|---|---|
| 第七届 | 华南师范大学 智能反诈骗小组（冼嘉荣/袁基保/谭可慧） | 电信网络诈骗智能识别/反诈（金融安全边角） | 中国创新赛三等奖 | [链接](http://news.scnu.edu.cn/57745) |

**检索结论**：以"金融/银行/保险/证券/投研/风控/信贷/支付/数字人民币/供应链金融"等关键词多轮检索，第八至十届创新赛**未发现任何金融类获奖作品**。原因推测：① 创新赛偏好"可演示的硬件 + AI"，金融场景难现场演示；② 企业命题集中在病理、制造、低空；③ 金融数据合规门槛高，学生难获取。
**因此金融是四方向中竞争最小、最容易做出差异化的赛道**，可行切入点：反诈/异常交易识别（已有先例）、信贷尽调报告生成、保险理赔单证多模态审核、投研公告问答、网点/押品巡检（复用无人机与视觉方案）。
