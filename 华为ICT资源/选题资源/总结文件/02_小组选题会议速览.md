# 赛道三小组选题会议速览

日期：2026年10月25日。详细方案见《01_赛道三选题研究与建议.md》。

## 建议先讨论这三个

| 选题 | 一句话说明 | 什么时候选 | 最小演示 |
|---|---|---|---|
| 惠企政策资格核验 | 把政策、指南、报表、证照关联起来，判断能否申报以及缺少什么证据 | 暂无行业合作资源 | 旧政策判断一次，新政策导入后重算并展示差异 |
| 制造质量追溯 | 把检验单、批次、物料、工艺规范关联起来，判断哪些批次需要复检 | 有工厂或校企真实数据 | 异常追溯到批次和规范，规范改变后列出影响集合 |
| 上市公司风险核验 | 把年报表格和多类公告交叉核对，输出有依据的风险复核清单 | 有财务指导、主要依赖公开资料 | 核对担保与主体关系，新公告到来后更新证据链 |

另外三个备选：设备故障处置、医疗器械召回资产匹配、政务采购材料合规核验。设备题需要工单，医疗题需要台账，采购题需要完整需求与响应材料。

## 必须保住的六件事

1. 至少有文本、表格、图文等异构材料，并登记统一资产ID。
2. 有低资源半自动本体构建，明确人工确认环节。
3. 有规范或知识更新，展示本体变化及其决策影响。
4. 在Nexent运行，真实调用MCP工具并通过Skills完成业务流程。
5. 结论可回到原文证据；缺材料时输出证据不足。
6. 有可复用Skill模板和可复现实验，而非只有聊天页面。

## 先问数据 再定题

| 问题 | 通过条件 |
|---|---|
| 一周内能拿到数据吗 | 至少3类相互关联资料，并说明来源与权限 |
| 谁来判断结果对不对 | 至少一位领域教师或实际业务用户愿意审核 |
| 真要跨文档吗 | 至少5个问题必须联合两份及以上资料 |
| 更新能改变什么 | 能演示一项规范变化引发的本体和决策变化 |
| 初赛能做出来吗 | 单行业、单业务、不依赖训练基础模型 |

## 会议推荐结论

无合作资源：政策核验作为主选题，上市公司风险核验作为备用题。有真实制造数据：将质量追溯提高到优先候选，再用同一标准比较。

建议预留8周，3人分别主责平台集成、图谱算法、数据业务与评测。前一周先做10份材料、5个案例、1次更新的小验证，跑通再定完整规模。

## 避免误判

- 初赛四项各25%，本题的算法与本体工作占有明确分量。
- 模板要求代码附件；选题后要准备可运行原型、截图和配置说明。
- 所有准确率、提速和节约成本都要实测，不把预期写成成绩。
- 提供的C4-AI PDF是鸿蒙赛道复赛名单，不是往届ICT赛道三名单。
- 本次未能核实具体往届ICT获奖项目；不能据此声称某方向曾在ICT获奖。
