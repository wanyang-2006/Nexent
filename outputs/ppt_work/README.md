# outputs/ppt_work/

答辩 PPT 修改版的生成材料（2026-11-04）。成品：仓库根目录 `基于仿真交易图的涉诈资金链路识别与证据工单辅助研判_修改版.pptx`，原稿未改动。

| 文件 | 内容 |
|---|---|
| `build_ppt.py` | 在原稿基础上重排第 2–16 页：保留模板背景与装饰图，重写内容页，新增“平台配置”“知识库检索”两页 |
| `patch1.py`、`patch2.py` | 两轮排版修正（已应用到 `build_ppt.py`，仅留作记录） |
| `orig.pptx` | 原稿副本 |
| `base.pptx` | 原稿复制两份内容页框架后的底稿，`build_ppt.py` 的输入 |
| `img/` | 页面截图素材：MCP 连接（内网地址已遮盖）、工具与技能页、版本管理、知识库、A0209 只读工单运行截图、监管问答运行截图 |
| `cand/`、`r1/`、`r2/`、`r3/`、`orig/` | 截图候选与逐轮渲染预览，可删除 |

重新生成：

```bash
python build_ppt.py base.pptx out.pptx
```

数据来源：评测数字取自 `eval/result.md`；重判名单取自 `core.api.rejudge('v1','v2')`；平台配置、版本和运行截图于 2026-11-04 取自 Nexent 页面（只读，未发送消息）。
