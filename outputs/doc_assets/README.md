# outputs/doc_assets/

开发设计文档（赛事模板 docx）第一至三章的生成材料。2026-11-03 新建。

| 文件 | 内容 |
|---|---|
| `content.py` | 第一至三章正文，以及简介表的“摘要”（`ABSTRACT`，≤500 字）和“应用技术”（`TECH`）两栏（要改文字就改这里） |
| `build_doc.py` | 把正文写入模板：替换“第一章”之后的部分，并填写简介表的摘要、应用技术两栏；封面、队伍信息、团队分工、智能体展示不动 |
| `draw_arch.py` | 画图 1-1 系统总体架构，输出 `architecture.png` |
| `platform_tools.png` | 图 1-2，Nexent 智能体配置页截图（已裁掉顶部账号） |
| `chain_L-T01908.png` | 图 1-3，由 `eval/graphs/v1_L-T01908.png` 裁边得到 |
| `模板原件_备份.docx` | 未填写的赛事模板原件 |

重新生成（仓库根目录执行，会覆盖根目录下的模板 docx）：

```bash
cd outputs/doc_assets
python build_doc.py 模板原件_备份.docx "../../【赛题3-模板1】创新赛-开发设计文档-学校-队名-队长姓名-手机号 （初赛阶段）.docx"
```
