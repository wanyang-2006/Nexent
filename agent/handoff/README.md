## 演示顺序

1. 打开原智能体，说明当前使用合成数据、仿真内部规则。
2. 查询A0209/v1，核对L-T01908、风险规则、交易编号、反向和缺失证据。
3. 查询A0105/v1，核对工资证据T01736及未见异常；V8已有三次普通独立请求通过，有限样本不保证任意请求永不失败。
4. 对比A0176/v1与v2，核对v2链L-T01338；运行rejudge核对300账户8升级。
5. 读取已有工单，确认读取流程；查询A9999，确认停止研判。

旧V5曾出现DSML调用文本或截断正文，V8开启协议修复后的本轮15次未复现。今后遇到时仍须记录失败，不能把文本中的工具名当作实际执行。
