2. 在服务器按需检查服务（不要求重启）：

```bash

cd ~/fundtrace-mcp
MCP_MODE=real .venv/bin/python mcp_server/selftest.py http://127.0.0.1:8900/sse
```

预期active及8工具19调用PASS。若失败先排查，不用历史工单冒充实时成功。

3. 全数据覆盖为2026-03-01 00:00至2026-03-07 23:59。get_account.first_tx_time/last_tx_time仅是该账户首末交易时间，不是全数据窗口。

## 可复制问题

### Q4 规则说明

```text
仿真内部规则 v1 中，“快进快出”是什么规则？判断条件和依据是什么？与 v2 有什么区别？
```

核对：R01、转账、v1 60分钟/v2 120分钟、转出为转入90%至110%、转入合计不少于10000元，有实际知识检索引用；不调用业务工具。

### Q1 完整研判

```text
请按 v1 研判账户 A0209，结合规则知识库生成工单。
```

核对：TK-v1-A0209、REVIEW/建议人工复核、中转端、L-T01908；R01/R04/R07/R08。五条边为T01908 A0044→A0283 35710元、T01913 A0287→A0283 36059元、T01932 A0283→A0209 70850元、T01938 A0209→A0177 70396元、T01942 A0177→A0186 70093元。前两条并行汇入，不能串成A0044→A0287。末端仅限当前窗口/深度可见。

### Q3 反向证据

```text
请按 v1 判断账户 A0105 有风险吗？请结合规则、工资证据和证据缺口说明。
```
