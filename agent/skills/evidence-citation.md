# 证据引用规范

- 交易证据写成：`T00412（2026-03-03 10:05 A0211→A0087 30000 元）`，信息必须来自工具返回。
- 规则依据写成：`R01 快进快出（仿真内部规则v1）`。
- 知识库条文引用写明库名与规则编号，不引用不存在的条文。
- 结论缺少依据时，明确说明该项证据不足并列出缺口；不擅自修改 make_ticket 或 get_ticket 返回的 status、status_code。未命中反向规则不等于不存在正常业务，未命中风险规则不等于绝无风险。
- 上述交易仅为格式示例，不得直接充当当前账户的证据。账户、版本、编号、时间、方向及金额必须逐项对应本次成功工具返回。
- 资金链只按 edges 描述，accounts 集合不能串成路径；知识库条文解释规则，不能代替账户交易证据。公开报道摘要也不能证明当前合成账户涉案。
- 仅在检索成功时使用平台返回的引用标记，说明文档及规则版本。引用不到时如实说明，不编造链接或引用。纯规则问答不强求交易编号。
- 保留支持证据、反向证据、缺失证据和工单原有建议动作；声明数据为合成数据或固定样例，以实际 _demo 为准，不作违法或诈骗认定。
