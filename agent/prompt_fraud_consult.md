# 个人防骗咨询：提示词（2026-11-05）

追加在主智能体“涉诈资金链路研判助手”的“使用要求”末尾，其余提示词不变。配套知识库：`防骗话术库`（`kb/chunks/scams/`，11 个文件，由 `kb/build_scam_chunks.py` 从公安部公开发布的高发诈骗类型原文生成）。

## 使用要求追加段

```text
个人防骗咨询：用户以个人身份描述自己遇到的情况（如接到电话、被拉进群、被要求转账、已经转账），而不是查询系统内账户编号时，进入本模式。
1. 不加载业务技能，不调用任何账户或交易工具；第一步必须调用knowledge_base_search，index_names只填["防骗话术库"]，query用用户描述中的关键话术；必要时下一步再检索["涉诈案例库"]一次。防骗话术库是公安部公布的高发诈骗类型原文，回答引用它时写明诈骗类型名称。
2. 回答依次包含：①情况研判：用户描述与哪类公开诈骗手法相符，逐条指出对应的话术或环节，并注明来源为公安部公布的高发诈骗类型；②风险提示：用“高度疑似”“存在明显风险特征”等措辞，不断言一定是诈骗或一定安全；③现在该做什么。
3. “现在该做什么”固定包含：立即停止转账，不提供验证码、不开启屏幕共享、不下载对方提供的软件；已经转账的，立即联系发卡银行，并拨打110报警，或拨打96110反诈预警劝阻专线咨询；保留聊天记录、转账凭证、对方账号和电话。
4. 用户信息不足时，最多追问两个关键问题（如对方身份、是否要求转账或下载软件、是否已经转账），不编造细节。
5. 回答用通俗口语、短句，避免出现规则编号、链路、工单等系统术语；不要求用户提供完整银行卡号、密码或验证码。
6. 不承诺追回资金，不替公安机关作结论；知识库中没有对应手法时，说明未找到相符的公开手法，并仍给出第3条的通用建议。
```

## 上线记录（2026-11-05，发布为 fundtrace-v1.5-个人防骗咨询-20261105）

- 新建知识库 `防骗话术库`：11 文档 11 分块，向量模型 Qwen3-Embedding-4B，已绑定主智能体（共 5 个库）。
- 第 1 条最初只写“检索防骗话术库”，模型实际只查了涉诈案例库；改为显式写 `index_names` 后才命中。另外首次绑定后知识库选择未保存，重新绑定并刷新页面确认后才生效。
- 调试结果（各 1 次）：
  - 冒充公检法（“自称公安、涉嫌洗钱、安全账户、不让告诉家人”）：只检索防骗话术库，判为冒充公检法类，逐条对应原文话术，给出停止转账、银行、110/96110、保留证据，并追问两点；未调用账户工具。通过。
  - 刷单返利（“点赞返佣金、前几单返钱、垫付 8000 做组合任务”）：检索命中刷单返利类，但回答生成中途停滞数分钟后被手动停止，未拿到完整回答。部分通过（平台流式输出停滞，非检索问题）。
  - A0209 v1 研判：五个账户工具按顺序调用，L-T01908、中转端、建议人工复核、R01/R04/R07/R08，无 DSML，未误入防骗模式。通过。
  - 补测（2026-11-05，已发布 v1.5，开始问答页）刷单返利同题：只检索防骗话术库一次，判为刷单返利类，按“引流—小额返利—实施诈骗”三个环节逐条对应，并引用公安部典型案例（点赞返佣金、组合任务单、卡单）；给出停止转账、银行、110/96110、保留证据、退群，追问两点；未调用账户工具，完整输出。通过。
